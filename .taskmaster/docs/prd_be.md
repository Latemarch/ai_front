# 프로젝트 개요  
투자 포트폴리오 관리 앱 - 대화형 인터페이스를 통해 사용자가 투자 포트폴리오를 생성, 최적화, 관리할 수 있도록 돕는 AI 기반 챗봇. 개인화된 포트폴리오 전략과 자동 리밸런싱, 커뮤니티 공유 기능을 원하는 개인 투자자들을 타겟으로 함.

# 핵심 기능

## V1 핵심 기능 (MVP)

- **AI 포트폴리오 어드바이저 챗봇**: LangChain 기반 대화형 AI로 백테스팅과 전략 추천을 통해 포트폴리오 구성 지원
- **대화형 포트폴리오 빌더**: 채팅 대화를 통해 포트폴리오 배분을 수정할 수 있는 기능
- **백테스팅 엔진**: 포트폴리오 전략에 대한 과거 성과 분석
- **포트폴리오 리포트**: 완성된 포트폴리오를 기반으로 한 투자 보고서 생성

## V2 확장 기능

- **자동 리밸런싱**: 사용자 전략에 따른 서버 측 포트폴리오 리밸런싱 실행
- **스마트 알림**: 리밸런싱 이벤트와 거래 실행에 대한 이메일/SMS/메신저 알림
- **전략 공유 플랫폼**: 포트폴리오 전략을 공유하고 발견할 수 있는 커뮤니티 기능
- **실시간 포트폴리오 추적**: 실시간 성과 모니터링 및 분석

# 사용자 경험

## 사용자 페르소나

- **주타겟**: 기초~중급 투자 지식을 가진 개인 투자자 (25-45세)
- **부타겟**: 전략을 공유하고 발견하고 싶어하는 투자 애호가들

## 주요 사용자 플로우

1. **포트폴리오 생성 플로우**: 채팅 → 백테스팅 → 전략 개선 → 리포트 생성
2. **포트폴리오 관리 플로우**: 모니터링 → 리밸런싱 알림 → 실행 → 성과 추적
3. **커뮤니티 플로우**: 전략 탐색 → 가져오기 → 커스터마이징 → 자신의 전략 공유

## UI/UX 고려사항

- 포트폴리오 구성을 위한 채팅 우선 인터페이스
- 포트폴리오 모니터링을 위한 깔끔한 대시보드
- 알림을 위한 모바일 반응형 디자인

# 기술 아키텍처

## 시스템 구성 요소

- **프론트엔드**: Next.js (별도 리포지토리로 분리 관리)
- **AI 백엔드**: FastAPI + LangChain을 이용한 대화형 AI 및 포트폴리오 분석 (본 프로젝트)
- **데이터베이스**:
  - ChromaDB (AI 컨텍스트 및 전략 임베딩을 위한 벡터 저장소)
  - MySQL (사용자 데이터, 포트폴리오, 거래 내역 - V2)
  - Redis (캐싱, 세션 관리 - V2)
- **인프라**: 로컬 개발 환경, CI/CD용 Github Actions

## 데이터 모델

### V1 모델

- 사용자 세션 데이터 (임시, ChromaDB)
- 포트폴리오 구성 (자산, 배분, 전략)
- 백테스팅 결과 및 과거 데이터
- 채팅 대화 기록

### V2 추가 모델

- 사용자 계정 및 인증
- 포트폴리오 실행 기록
- 알림 설정 및 로그
- 공유 전략 마켓플레이스 데이터

## API 및 통합

- **외부 API**: 금융 데이터 제공업체 (Alpha Vantage, Yahoo Finance 등)
- **내부 API**:
  - 채팅/AI 서비스 엔드포인트
  - 포트폴리오 관리 엔드포인트
  - 백테스팅 서비스 엔드포인트
  - 사용자 관리 (V2)
- **알림 서비스**: 이메일 (SendGrid), SMS (Twilio) - V2

## 인프라 요구사항

- 컨테이너 오케스트레이션 (Docker Compose → 확장을 위한 Kubernetes)
- 리밸런싱을 위한 백그라운드 작업 처리
- 시장 업데이트를 위한 실시간 데이터 스트리밍
- 금융 데이터 규정 준수를 위한 보안 저장소

# 성공 지표

## V1 성공 기준

- 사용자가 10분 이내에 포트폴리오 생성 대화를 완료할 수 있음
- 백테스팅 결과가 30초 이내에 표시됨

- 포트폴리오 추천이 사용자 위험 허용도와 90% 이상 일치함

- 전략 공유 플랫폼에 100개 이상의 활성 전략 보유
- 시스템이 1000명 이상의 동시 사용자를 처리함
